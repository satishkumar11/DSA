# DSA — Deloitte Interview Prep

88 data structures & algorithms problems, solved in both JavaScript and Java, curated for a
Deloitte SDE interview (DSA + system design round). Solutions live in [js/](js/) and [java/](java/),
with filenames prefixed by difficulty: `e-` (easy), `m-` (medium), `h-` (hard).

Each solution file's header includes the problem title, a one-line explanation of what it asks,
a two-line description of the approach used, and its time/space complexity.

See [deloitte-interview-prep.md](deloitte-interview-prep.md) for the research behind this list —
sourced from GeeksforGeeks, DSAPrep.dev, and real Deloitte interview threads on LeetCode Discuss.
